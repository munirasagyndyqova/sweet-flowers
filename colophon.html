Colophon

This page describes how the Sweet Flowers website was created.

Who created the website

The website was created by Nurziya Kenes, Sagyndykova Munira and Koshkinbayeva Akbota as part of an HTML basics assignment. Participant 3 was responsible for the technical pages, including this colophon. All pages were written by hand using a WebStorm and notebook.

How we collected information

Information about flowers and delivery was collected from public domain resources and by working at this place. We ensured that all data used is accurate and up-to-date, relying on official KZ suppliers. We also will use CSS for basic styling later in the project.

How we organized HTML

The website is organized into several pages. Each page is linked through a common navigation menu. The main structure uses semantic HTML5 tags like <header>, <main>, <section>, and <footer>.

Here is an example of the file structure:

sweet-flowers/
├── images/
├── index.html
├── about.html
├── delivery.html
├── flowers.html
├── order.html
├── reviews.html
├── contacts.html
└── colophon.html

What tools we used

We used a WebStorm and notebook. To speed up the process, we used keyboard shortcuts like Ctrl + C to copy and Ctrl + V to paste code snippets.

When validating our HTML, we sometimes saw errors. For example, the validator output looked like this:

Error: Element 'div' not allowed as child of element 'ul' in this context.

We fixed these issues by using the correct semantic tags.

We used W3Schools and YouTube channels tj create this site and solve the errors....

How pages are connected

All pages are connected via relative links in the <nav> element. For example, to go to the contacts page, we use <a href="contacts.html">Contacts</a>.

We also used relative paths to link images and other resources, ensuring the site works locally without a web server.

What we learned

We learned how to structure a multi-page website, the importance of semantic HTML, and how to use various text-level semantics like <q>, <cite>, and <address>.

Special characters like &amp; and &lt; must be encoded as HTML entities to display correctly. For example: <html> & ©.

Code is like humor. When you have to explain it, it’s bad:(

This quote resonated with our team as we tried to keep our markup clean and self-explanatory.
